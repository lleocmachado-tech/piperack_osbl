# Marcador de avanço em PDF

Pinte as peças sobre os desenhos PDF para marcar o avanço e baixe o PDF colorido.

O app está em [`marcador-pdf/`](marcador-pdf/README.md). No Netlify, defina **Base directory** = `marcador-pdf`.

O app anterior (FastAPI + worker + OCR, "COMBIO · Avanço PipeRack OSBL") foi removido e continua no histórico do git, no commit `83de462`.

Desenhos, banco e relatórios da obra não vão para o Git (`Desenhos/`, `data/`, `reports/`).
